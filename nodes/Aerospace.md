# Aerospace

Aerospace is a tiling manager and workspace manager.

---
# General

Aerospace solves a problem that is not solved natively on the macOS.
It allows you to split/move your app's windows into virtual displays (workspaces).
It allows you to snap into the four corner and resize each window.

> [!warning] Resizing only works when you are in split mode (you have at least two windows side by side or above/below each other).

Find the aerospace.toml configuration file in the ubuntu-setup repository.

The keybindings are very similar to neovim's but instead using control I use option (alt) key so the combinations don't clash.
